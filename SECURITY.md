# Security Policy

## Purpose

Endpoint Log Analyzer is an educational and portfolio project for security-log analysis.

## Reporting a vulnerability

If you find a security issue in the project itself, please open a GitHub issue with enough detail to reproduce it.

Do not include credentials, API keys, real customer logs, personal information, or confidential security data in issues or pull requests.

## Responsible use

Only analyze logs and systems you are authorized to access.
